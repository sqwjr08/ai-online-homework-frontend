# 21a：教师提交与批改详情

2026-10-04代码完成；浏览器和真实后端联调尚未执行。入口：教师工作台 → 班级作业 → 查看提交与批改。

## 接口与边界

以下路径均加`/api/v1`，由统一请求层发送Bearer。本页面仅教师角色可进入，后端仍负责班级归属校验；管理员教学入口另定范围。

| 接口 | 使用方式 |
| --- | --- |
| GET `/assignments/{id}` | 教师题面、图片、参考答案、rubric及满分；按question_source注明snapshot/draft_preview/legacy_reference |
| GET `/assignments/{id}/submissions` | page、page_size（界面20/50/100）、可选status= pending_teacher_review或confirmed；items/total/page/page_size/progress |
| GET `/submissions/{id}` | 单独读取教师详情；校验view=teacher、assignment_id和提交id，拒绝错配响应 |

progress中的submitted_count/pending_count/confirmed_count是整份作业统计，不随列表筛选变化。接口未提供全班人数、未交名单或学生姓名，因此只显示学生ID，不构造完成率。列表没有AI状态筛选接口。

人工状态与AI状态分别展示。AI支持pending/processing/succeeded/failed/cancelled/legacy_unknown；分数为0时照常显示，null表示尚无结果。AI分数/评语始终标注草稿，教师最终分数及评语只在confirmed下显示。另展示尝试次数、人工重试计数、下次尝试时间及安全映射的错误说明，未知错误不直接展示服务商原文。响应不含provider/模型信息，不能声称草稿来自真实大模型。

对照按question_id匹配，不按答案数组位置。题面来自作业响应，不请求当前题库替代历史快照；缺题、重复或孤立答案会显示警告和未匹配原文。作业题面409失败时列表与提交详情仍可独立读取。刷新失败清空旧结果，切换筛选/页码关闭旧详情；取消和请求版本检查防止迟到响应串到其他作业或学生。

归档作业也可通过教师作业列表进入，读取能否成功由后端权限决定。时间按浏览器时区显示并注明时区。页面无确认、更正、重交、AI重试或自动轮询；人工确认留21b，有限重试留21c。AI故障不构成将来人工评分的前置阻塞。

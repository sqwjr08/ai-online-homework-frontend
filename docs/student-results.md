# 20c：学生成绩与历史边界

2026-10-04代码完成；浏览器及真实后端联调待执行。入口：我的作业 → 查看题面与本人提交 → 查看本人答案与成绩；也可从学生工作台的“答案与成绩”按已知编号查询。

## 路由与接口

| 前端地址 | 数据来源（均加/api/v1） |
| --- | --- |
| `/student/results` | 编号查询入口，不请求或伪造历史列表 |
| `/student/submissions/:submissionId` | GET `/submissions/{submission_id}` |
| `/student/assignments/:assignmentId/result` | GET `/assignments/{assignment_id}/submissions/my` |

以上只允许登录学生进入。后端按本人提交归属授权，不依赖当前所属班级或作业可见性。前端额外核对view=student、student_id=当前会话用户及目标编号，拒绝教师视图和错配响应。收到提交后尝试GET `/assignments/{assignment_id}`，只使用学生安全题面，按question_id对照；不请求教师题库或参考答案。

显式白名单仅保留本人答案、状态、时间及确认后的最终分数/评语。pending_teacher_review时强制丢弃总分、逐题分数、评语和确认时间，即使响应意外填值也不会展示。confirmed时零分保留，null与缺失标为未记录，不推算逐题成绩或补造答案。文字通过Vue文本插值展示，保留换行，不解释HTML。

读取与刷新先清除旧数据；403/404/422分别提示无权、无记录和编号问题。题面读取失败不抹掉已读取的本人答案/成绩；独立显示题面不可用提示。切换编号、离页或账号改变时清理，取消旧请求并忽略迟到响应。只手动刷新，不轮询、不触发AI，不保存本地成绩或历史缓存。

## 历史功能的明确边界

本轮只读核对后端远端main仍为`762150996adbea01e4ce02fc779d3ed0e7f8f571`，未发现学生完整历史列表接口或归档学生题面接口：

- `app/api/routes/submissions.py`：本人记录可按已知作业编号/提交编号读取；没有全部本人提交分页列表。
- `app/api/routes/assignments.py`：学生只可访问已发布作业，归档后题面不可读，作业退出学生列表。
- `StudentSubmissionRead`：无作业标题、题干、图片及满分。归档后只能展示编号、原答案及已确认成绩；不通过当前题库拼凑历史题面。

因此当前交付是**已知链接/编号查分**。页面提供可收藏的固定提交链接，打开仍需本人登录；这不是公开分享链接，也不能替代完整历史发现功能。若未保存链接或编号，换设备后不能从前端找到全部归档记录。建议后端后续提供学生本人提交分页摘要及归档安全题面；本轮未擅自修改后端。

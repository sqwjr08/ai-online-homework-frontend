# 作业草稿：19a

更新日期：2026-09-30。代码和针对性自动化验证完成，实际浏览器检查及真实后端联调待执行。

## 范围

教师工作台“作业草稿”进入 `/teacher/assignments`。支持草稿列表、创建、读取并编辑、启用班级选择、启用题库搜索分页、选题去重、上移下移与移除引用、标题说明和可选截止时间。复用图片只读组件展示题面，参考答案和标准在教师页折叠展示。

不开放发布、归档、删除、转班、延期或学生作业页面。管理员入口未扩展。学生不能进入此教师路由，真实所有权与角色权限仍由后端执行。

## 已核对的接口

基于只读后端路由、schemas、assignments/questions服务、assignment-lifecycle及assignment-snapshots文档。远端main本轮仍为 `762150996adbea01e4ce02fc779d3ed0e7f8f571`。未启动后端取OpenAPI，未修改后端。

以下均加 `/api/v1`：

| 接口 | 请求与响应重点 |
| --- | --- |
| GET /assignments/my?status=draft | 返回AssignmentRead数组，无分页或标题搜索；教师按班级所属关系读取，并非简单created_by过滤 |
| GET /assignments/{id} | 每次打开从服务器读取最新内容；status非draft只读；403/404/409明确失败，不回退旧列表详情 |
| POST /assignments | 明确发送status=draft（后端默认published！）；class_id/title/description/questions/due_at；201返回教师视图 |
| PATCH /assignments/{id} | 仅title/description/questions/due_at；不发送class_id/status/revision/snapshot；仅草稿和启用班级可改 |
| GET /classes/my?is_active=true | 启用班级数组，供创建选择；无班级时引导先建班 |
| GET /questions?is_active=true&page=…&page_size=20&q=… | 教师自有启用题库，字面题干搜索和分页；已锁定但启用的题目仍可选用 |

标题trim后1–200字符。description为空发送null；questions是有序 `{question_id}` 数组，至少一题且不重复，没有客户端position或快照字段。服务端响应含题干、图片、满分、参考答案、标准和position，草稿内容来源为draft_preview；只有发布后才形成正式快照。

编辑时班级不可更换。题目数组全量替换；无效/停用题400，跨教师题403；归档班级、非草稿、并发变化或损坏引用可409。旧草稿若包含停用题，重新提交整组题目可能被400拒绝，需据实际内容调整，不能绕过限制。

## 锁定、时间与失败处理

- 保存草稿即永久锁定所选题目；移除引用也不解锁，保存失败可能留下保守锁。页面提示并要求勾选确认，没有“临时草稿不会影响题库”的假设。
- 日期输入明确标出浏览器本地时区，保存转换为带Z的UTC，读取转回本地，保留毫秒。不使用服务器或浏览器猜测的无时区字符串发送。未更改的已有截止时间保留原瞬间，避免夏令时重复小时造成偏移；手动输入不存在的日期或跳过时段会拒绝。
- due_at=null表示无截止时间。草稿允许过去日期，正式发布时需满足服务器检查，19a不预先伪造发布能力。
- 防重复保存。成功后使用响应回填并刷新列表；列表刷新失败不抹去已确认保存成功。刷新网页后可以从列表重新打开已保存草稿，未保存输入不会跨页持久化。
- 400/403/404/422保留输入并反馈；409与网络/超时/5xx暂停再次保存。编辑读取最新详情供核对，不覆盖草稿；最新非draft不能解除保存阻断。创建结果不确定时先重新读取草稿列表，不凭同标题认定成功，也不自动POST重试。
- 后端revision只在一次请求内部做条件写入，响应/请求不提供浏览器版本条件；不能宣称防止所有长期打开页面导致的后写覆盖。多人编辑仍需协调。
- 列表/详情迟到响应保护，离页清理题面及表单。没有全局作业缓存或浏览器答案存储。

文档中旧节点09关于“评分后保存前检查截止”的同步评分叙述属于历史状态；本节点只依据当前草稿实现，不据此改变后续异步提交业务。

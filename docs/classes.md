## 范围与接口

教师工作台“班级”进入`/teacher/classes`，仅教师角色。管理员班级功能和学生入班不在本节点，后端的管理员权限不等于本轮已开放管理员页面。

只读核对后端`app/api/routes/classes.py`、`app/services/classes.py`和`app/schemas.py`；远端main仍为`762150996adbea01e4ce02fc779d3ed0e7f8f571`。

| 接口（统一/api/v1前缀） | 本轮用法 |
| --- | --- |
| GET /classes/my | 直接数组，is_active省略/true/false表示全部/使用中/归档；教师只能读本人班级，没有列表分页 |
| POST /classes | 仅发送name，不发送teacher_id；教师归属由后端判定，名称去首尾空白后1–100字符；201返回班级和六位班级码 |
| GET /classes/{id}/members | page/page_size/is_active；UserPage包含items/total/page/page_size，每页20/50/100，页码最高1000000；归档班也可查看 |
| POST /classes/{id}/archive | 无请求体，返回ClassRead；重复归档幂等，无恢复接口 |

ClassRead为id/name/code/teacher_id/is_active/created_at。成员展示用户名和启用状态，不虚构真实姓名；筛选后的total不是全部班级人数。后端成员按创建时间、ID升序，班级按创建时间、ID降序。

## 操作与限制

- 班级码显示为可选中文字；已归档班标明不能新入班，不添加未验证的复制能力。
- 同名班级允许存在，不能把名称当唯一ID。建班网络/超时/5xx结果不明时禁止直接重复提交，先显式刷新核对班级码/状态；不能因同名项出现就宣称刚才成功。无自动POST重试。
- 归档前显示目标及影响：阻止新入班、新建作业、草稿编辑/发布及新提交；保留成员、历史读取及教师成绩确认；不会自动归档已有作业；不能恢复。
- 归档成功按当前班级筛选重新加载。建班成功切换全部班级，显示服务端班级码。列表刷新失败与写入成功分别反馈。
- 切换班级/筛选时取消旧读取，迟到的成员响应不能覆盖新班级；退出或离页清理列表和成员。不缓存跨账号班级数据。
- 403/404等错误明确显示，不当作空班级；归档失败需要重新选择确认。前端守卫不替代后端教师所有权校验。
- 本节点不提供班级改名、删除、恢复、学生移除/转班、作业发布、管理员选教师建班。

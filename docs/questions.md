## 范围与接口

教师工作台“题库”进入`/teacher/questions`。本节点只开放教师入口，管理员题库导航另行规划；后端本身允许管理员使用题库API。学生不能进入，也不请求该接口获取答案。

只读核对后端questions路由、schemas和questions服务，远端main仍为`762150996adbea01e4ce02fc779d3ed0e7f8f571`。接口均加`/api/v1`：

| 接口 | 契约 |
| --- | --- |
| GET /questions | page 1–1000000、page_size 1–100；q最多200字符，按题干字面包含搜索且忽略大小写；is_active默认true，false仅停用，没有“全部”选项；教师只读自己创建的题目 |
| GET /questions/{id} | QuestionRead；403/404不能回退成旧列表里的详情 |
| POST /questions | prompt/reference_answer/max_score/rubric/image_urls；201返回QuestionRead，创建成功不代表已发布作业 |

题干去首尾空白后1–10000字符；参考答案1–20000；评分标准可留空（发送null），明确填写时1–5000且不能全空白。满分为大于零的有限JSON数值，不擅自限制为整数或两位小数。创建时image_urls来自已上传图片（无图为[]）；编辑未调整图片时省略image_urls，调整后发送完整引用数组，清空时发送[]。

QuestionRead包含id/prompt/reference_answer/max_score/rubric/image_urls/created_by/is_active/created_at/updated_at；没有can_edit或content_locked。启用不等于未引用/可编辑。列表为items/total/page/page_size，创建时间和ID倒序。

## 实现与边界

- `src/questions/questions.js`管理列表、详情、创建、校验和竞争保护；`src/views/QuestionsPage.vue`负责界面。无全局题目缓存、不写浏览器存储；离页清理列表、详情和表单。
- 搜索提交及状态筛选从第一页查询，每页20/50/100条；查询取消旧请求，迟到响应不覆盖新列表或详情；加载/空/失败分别反馈。
- 参考答案、评分标准仅在受保护教师页面展示，使用Vue文本插值及保留换行，不使用v-html或未经净化的富文本。学生题面后续必须来自学生作业接口。
- 创建时禁用重复操作；成功清表单并展示服务端返回详情、ID，切换启用题第一页；后续列表失败不掩盖已确认创建成功。
- 422映射字段错误，不回显原始输入；其他失败保留表单。超时/网络/5xx先暂停再次提交，通过题干前200字符检索核对；同题干允许重复，匹配结果不能证明是本次写入，不能自动重试POST。刷新网页会丢失未保存表单及本页未决状态。
- 18c已支持题目图片上传、详情预览、编辑和移除引用；显示失败明确提示题面可能不完整。18b编辑/停用规则继续生效。

## 18c：题目图片（2026-09-30）

### 接口与显示

- POST /api/v1/uploads/images，FormData字段file，教师/管理员可用，200返回{url}。沿用请求层Bearer和401失效处理，不手写multipart边界，不直接调用静态URL上传。
- 静态图片公开读取，img直接加载服务端URL，不通过带Bearer的API客户端；不发送页面Referer。接受无凭据HTTP(S) URL及/uploads/images/相对路径，拒绝data/javascript/协议相对地址等。无任意URL输入框，不向学生请求教师题库。
- 不重写PUBLIC_BASE_URL：后端默认http://localhost:8000，部署应配置浏览器可访问的地址，HTTPS页面须配HTTPS图片服务。/uploads相对路径使用已有开发代理，生产环境也须代理该路径。图片失败有明确提示，不假装完整题面。
- 已只读核对docs/images.md、上传路由、images服务和QuestionCreate/Update；远端main本轮仍为762150996adbea01e4ce02fc779d3ed0e7f8f571。没有启动服务获取运行时OpenAPI。

### 上传和保存边界

- 每次选择一张JPEG/PNG，前端先检查MIME、非空和最多5 MiB，再解码检查单边10,000和总像素20,000,000；本地对象URL在成功、失败、取消时释放。最终格式、损坏、MIME伪装、APNG、输入/重编码输出大小仍以服务器校验为准；前端不压缩或重编码图片。
- 上传成功只添加服务端URL到当前表单，保存题目后才关联。上传中禁止保存，失败不加入无效URL；上传超时/5xx明确结果不确定、不自动重试。重新选择可能留下重复文件，没有删除/回收接口。
- 编辑时复制原图片数组，未调整图片则PATCH省略image_urls，避免纯文字编辑覆盖他人图片；调整后发送完整数组。移除引用只有保存后生效，不删除文件、不影响旧作业快照。
- 上传文件本身不判断某道题是否锁定；保存引用仍受题目PATCH锁定限制。409保留文字及图片引用，并展示最新题目和图片供核对。即使保存被拒绝，已上传文件仍可能留在服务器。
- 只读QuestionImage组件可以后续复用于学生作业题面；当前学生作业页未实现，没有学生上传/答案图片/识别入口。题图是公开资源，界面提醒不上传参考答案、评分标准或个人敏感信息。
- 离页/关闭编辑取消上传并忽略迟到结果；取消不保证服务端未落盘。未保存引用不持久化，已上传文件也不会随表单放弃而自动删除。

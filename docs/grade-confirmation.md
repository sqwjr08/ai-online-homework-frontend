# 21b：人工确认成绩

2026-10-04代码完成；浏览器和真实后端联调待执行。入口：班级作业 → 查看提交与批改 → 未确认提交 → 开始人工评分。

## 契约与操作

`POST /api/v1/submissions/{submission_id}/confirm-grade`，请求仅包含`grades`，每项为`question_id`、数值`final_score`、可空`final_comment`。按题目ID逐题提交，不发送总分、AI字段或教师ID。后端校验教师班级归属（也支持管理员，前端本节点只开放教师）。

- 必须是待确认记录、已发布作业（含由发布状态归档），题面和答案完整且唯一对应；草稿、归档草稿、题面不可读取或错配不能评分。
- 每题分数0至该作业题面满分，最多两位小数；不能留空。评语选填，按Unicode字符计数最多1000，去两端空白后为空发送null。总分按整数百分之一累加预览，最终以服务器返回为准。
- 字段初始为空，不自动采纳AI建议；pending/processing/failed等AI状态均不阻塞人工评分。确认时后端会取消仍待执行/运行中/失败的AI任务，页面仅采用响应状态，不自行触发worker。
- 勾选“核对并同意公布后不可更正”后才能提交；修改输入会取消勾选。防止重复点击，评分期间固定当前提交，列表切换和题面刷新暂停；取消或离页有丢弃提示，发送/查询期间阻止普通路由切换，会话失效仍允许退出。输入仅在内存，离页清理。
- 200返回教师完整提交，展示锁定成绩并刷新当前列表/全局进度。保留原输入供对照并明确不代表最终服务器结果，可结束查看。不存在更正入口。
- 409可能是他人抢先确认，也可能题目需要修复：自动GET该提交；已confirmed时显示服务器锁定结果；仍pending时再读作业，保留输入并要求人工核对后明确继续。不会自动POST。
- 超时/断网/5xx或响应不匹配属于结果不明，暂停确认；须手动GET提交和题面，确认仍可评分后再选择继续。先前请求仍可能延迟完成，最终由后端原子锁定拒绝重复写入。
- 400/403/404暂停并要求查询核对；422保留输入，映射安全的字段提示，不展示错误中的原始输入或服务商文本。查回失败不能解锁重发。

后端基线本轮只读核对远端main仍为`762150996adbea01e4ce02fc779d3ed0e7f8f571`。无后端修改、依赖安装升级、数据库、worker、AI或付费调用。

## 范围与接口

学生首页“我的作业”进入 `/student/assignments`。支持所属班级提示、已发布作业列表、题面/图片/满分、截止时间及本人提交状态。20a当时没有作答与提交；20b已接入文字作答和一次提交，仍无重交、撤回、答案图片上传或成绩详情入口。

本轮只读核对assignments/submissions路由、学生响应模型及submission_read逻辑；远端main仍为 `762150996adbea01e4ce02fc779d3ed0e7f8f571`。没有启动后端取OpenAPI。

| 接口（均加/api/v1） | 使用方式 |
| --- | --- |
| GET /classes/my | 当前归属数组；空数组显示未入班入口，归档班级说明不能新提交；失败独立显示，不把失败当成未入班 |
| GET /assignments/my?status=published | 服务器筛选当前学生本班已发布作业，数组无分页/搜索；不请求教师题库或其他状态 |
| GET /assignments/{id} | 学生题面，403为跨班/无权，404可能为未发布/归档/不存在；不能回退旧列表题面 |
| GET /assignments/{id}/submissions/my | 仅查当前学生本人提交；404才视为没有记录，401/403/网络/5xx均为查询失败，不得据此开放新提交 |

打开详情时并行读取题面与本人提交，列表不逐条查询提交，避免额外请求。两个读取结果独立：题面404不代表本人提交不存在，提交查询按所有权仍可能成功。作业归档后从已发布列表消失，本节点未增加归档历史列表或凭空发现旧作业ID的能力；已知作业在打开期间归档时仍可单独重新查询本人提交。历史导航缺口留待既定后续节点处理。

## 权限、数据与时间

- 学生路由受student角色守卫保护，真正授权仍由后端执行。只复用QuestionImage，不使用教师AssignmentReadOnly组件。
- 作业响应必须view=student且status=published；显式提取id/class_id/title/description/due_at及questions的question_id/position/prompt/image_urls/max_score。参考答案、rubric和额外字段不进入页面状态。若后端实际返回受限字段，仍属于后端泄露问题，前端投影不能替代后端权限保障。
- 本节点提交状态只保留id/status/submitted_at，不保留answers、AI字段或任何分数。pending_teacher_review显示“答案已保存，等待教师确认”，不推断AI完成或失败；confirmed仅提示教师已确认，成绩详情后续接入。
- 图片静态URL公开读取，沿用安全地址与失败提示。题干说明使用纯文本，不执行HTML。
- UTC时间转为浏览器本地显示并注明时区；截止等号算到期，无截止单独显示，本机提示每30秒更新（不轮询API）。以服务器判断为准，不把到期当归档，也不保证未到期就有提交资格。
- 列表、班级、题面及本人提交都有迟到响应保护；切换作业/关闭/刷新列表清理旧详情，离页取消并清空状态，不写浏览器业务缓存。

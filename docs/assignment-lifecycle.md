## 接口与规则

本轮只读核对当前后端assignments路由、服务、生命周期/快照文档；远端main仍为 `762150996adbea01e4ce02fc779d3ed0e7f8f571`。未启动服务获取运行时OpenAPI。

| 接口（均加/api/v1） | 前端行为 |
| --- | --- |
| GET /assignments/my | status=draft/published/archived；“全部”省略status；数组返回 |
| GET /assignments/{id} | 每次详情、预览、冲突核对均重新读取；失败清空旧详情，不能凭旧列表确认操作 |
| POST /assignments/{id}/publish | 无请求体；草稿预览后勾选确认；成功返回AssignmentRead并转只读，刷新当前筛选列表 |
| POST /assignments/{id}/archive | 无请求体；草稿或已发布作业确认归档；成功保留只读详情及实际内容来源，刷新列表 |

发布要求所属班级启用，截止时间若设置必须在服务器检查时仍未到达；无截止时间允许发布。前端不以本机时钟替代服务器判断，也不因本机时间误差自行拒绝请求。400提示截止或题目异常，读取核对后可返回草稿修改。

发布时服务器锁题、重新读题并生成快照。发布后不能编辑、延期、撤回或删除。本节点不发送status/deadline/snapshot/revision覆盖，也不开放这些无后端能力的操作。

草稿和已发布作业均可归档，归档班级中的已有作业也可归档；不能凭启用班级列表缺少班级就阻止归档。已归档作业仅供查看，不提供恢复或重新发布。后端publish/archive顺序重复请求可能幂等返回200，前端仍防重复点击、无自动重试。

归档后学生不能再读取该作业题面或新提交；已有提交保留，学生本人历史提交及已确认成绩仍按实际接口权限访问，不能宣称全部历史记录都隐藏或删除。静态题图仍公开。学生历史入口与提交/查分功能尚待后续节点。

## 内容来源与失败处理

- `snapshot`：发布时快照；`draft_preview`：草稿引用预览（归档草稿仍可为此值）；`legacy_reference`：历史题目引用。显示源自响应，不能由status推断是否有快照，不为旧作业伪造快照。
- 只读详情包含班级或明确班级ID、状态、截止时间和本地时区、说明、有序题面及图片、折叠的参考答案与标准。仅在教师受保护页面使用此组件，后续学生页面不得复用含教师答案的详情组件。
- 每次读取清除确认。写操作期间禁止重复点击、切换目标与关闭；400/403/404/409/422及网络/5xx后均暂停再次确认，须先重新读取、核对并重新勾选。
- 409可能来自并发状态变化、归档班级、损坏引用/快照；不自动认定为同一原因。不确定结果不重试POST；读取后若已发布/已归档，显示实际状态，不宣称一定是本次请求完成。
- 发布/归档成功后保留服务端返回详情，列表刷新失败不会改写已确认成功。列表/详情请求有竞争与离页保护，退出后不回填旧账号详情。
- 接口没有预览版本条件参数。预览和最终POST之间仍可能有其他操作修改草稿，前端不能承诺“发布的内容必然与之前预览逐字相同”；提醒避免同时编辑。服务器内部revision原子更新也不等于跨请求的浏览器版本锁。
- 损坏旧引用可能让整个列表返回409，本节点如实显示错误，不伪造部分成功数据。

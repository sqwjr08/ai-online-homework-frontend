# 学生注册与入班：17d

更新日期：2026-09-29。代码完成，浏览器与真实后端联调待执行。

## 页面和契约

- 登录页开放`/register`。仅未登录用户可停留，已登录账号转回自己的角色入口。注册无角色、启用状态或班级字段。
- POST `/api/v1/auth/register`只发username/password，skipAuth不携带令牌。用户名3–50字符且无空白/控制字符；密码4–128字符且非全空白，首尾空格保留，前端额外核对重复密码。201返回UserRead，不是登录令牌，成功后需自行登录。
- 学生首页“我的班级”到`/student/class`，仅学生可进。先GET `/auth/me`刷新会话资料，再结合GET `/classes/my`（两请求并行，不带is_active筛选）核实单班级关系。
- 未入班必须是me的class_id为空且班级数组为空；如果信息不一致或请求失败，显示错误，不提供未经核实的入班入口。已有归档班级也会显示，不当成未入班。
- POST `/classes/join`仅发送code，去首尾空白并转大写，格式为6位A–Z/0–9。成功后刷新me及班级，更新内存会话class_id。
- 后端先检查班级存在且未归档，再检查学生关系；同一有效班级重复加入幂等，跨班409，归档/无效码404。前端已确认入班后不显示重复提交或转班表单。
- 班级响应只展示名称、班级码和归档状态，不请求教师成员列表或题库，不虚构教师姓名。不提供退班、转班、归档后换班。

后端只读核对auth/classes路由、classes服务和schemas；远端main仍为`762150996adbea01e4ce02fc779d3ed0e7f8f571`。未启动服务读取运行时OpenAPI，后续仍应重新核实版本。

## 故障与数据清理

- 注册409提示已存在，422按字段提示且不回显原始请求。超时/断网/5xx结果不确定时停止本页再次注册，提示先尝试登录，不自动重复POST。
- 入班404提示核对班级码或归档情况；409主动读取当前关系，无转班流程；不确定结果必须先刷新当前班级，读取失败仍禁止再次入班。
- 写入成功与后续读取失败分别显示；成功保存不因刷新失败而宣称失败。刷新后仍无班级时可以再次显式提交，但先前请求仍可能延迟完成，后端最终处理单班级约束。
- 密码仅存在表单和发送请求期间，发送时即清空，离页也清空；不写浏览器存储、日志或URL。不自动登录，不缓存注册用户资料。
- 页面离开后忽略迟到结果，列表读取可取消；会话refreshUser有版本保护，退出后的迟到me不能恢复旧会话。学生未确认班级关系前不展示加入入口。
